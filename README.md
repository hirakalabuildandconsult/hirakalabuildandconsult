# Hirakala Build & Consult

Static, responsive frontend for Hirakala Build & Consult Pvt. Ltd. Open `index.html` in a browser or publish this folder through GitHub Pages/static hosting. Pages share navigation and footer through `js/main.js`; sample portfolio and blog content live in separate JavaScript data modules, ready to replace with CMS/API data later.

Forms currently provide a frontend confirmation only. Connect their submit handlers to email, Google Forms, Firebase, Supabase or a custom backend before production. Replace the sample Unsplash imagery and placeholder social profile links with official company assets and profiles.
